# Bubble to-do

Single-file web app (`index.html`) + Supabase for login and data.

- `index.html` – the whole app (deployed by Netlify)
- `sql/` – database changes, run once each in the Supabase SQL Editor
- `apps-script/bubbles_api.gs` – paste into the Google Sheet's Apps Script project (see the comment at the top)
- `docs/steps-shortcut.md` – how the iPhone sends steps to the sheet
- `sql/` – run every file there once, in number order, in the Supabase SQL Editor (paste the code, not the file name)
